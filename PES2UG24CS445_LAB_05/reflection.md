# Lab 5: Static Code Analysis — Reflection

## 1. What did you learn from this lab?

I learned how to use Pylint, Flake8, and Bandit to analyse Python code. These tools help identify code quality issues, style violations, and potential security problems. I also learned that code can run successfully and still contain issues that need to be corrected.

## 2. What issues did you identify and fix?

I identified several issues in the original Movie Theater Seat Reservation System. These included the use of a mutable default argument, overly broad exception handling, weak MD5 hashing, and insecure file permissions. I corrected these issues by using None as the default argument, handling specific exceptions, replacing MD5 with SHA-256, and restricting file permissions.

## 3. How did static analysis improve your code?

Static analysis helped me identify problems that were not always obvious when running the program. Pylint helped improve code quality, Flake8 identified formatting problems, and Bandit detected potentially insecure coding practices. After making corrections, I ran the tools again to verify the improvements.

## 4. What challenges did you face, and what did you learn?

I faced challenges understanding the reports generated by the three tools and correcting the issues without affecting the program's functionality. I learned to read warning messages, modify the code carefully, and rerun the tools to check the results. This lab showed me the importance of writing secure, readable, and maintainable Python code.
