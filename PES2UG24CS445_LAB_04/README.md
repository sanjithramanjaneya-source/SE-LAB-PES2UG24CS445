# Lab 4 – Tic-Tac-Toe Game

## Description
A Tic-Tac-Toe game developed using Python and Pygame.

## Features
- Win and draw detection
- Scoreboard for X, O, and draws
- Invalid move prevention
- Player selection
- Round restart
- Match reset

## Technologies
- Python
- Pygame
